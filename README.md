# SkinMatch
A SkinMatch é uma app inteligente de cuidados com a pele. Recolhe o histórico do utilizador e analisa a foto do rosto via YouCam API (avaliando acne e poros). Gera pontuações, cria rotinas diárias para dia e noite, monitoriza o progresso ao longo do tempo e recomenda produtos do nosso catálogo adequados às necessidades identificadas
